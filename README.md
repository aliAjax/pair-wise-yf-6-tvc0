# 家庭维修垫付台

端口规划：`5114`

```bash
npm install
npm run dev
```

费用垫付闭环：

- 每个维修事项可登记多笔垫付，写清付款人、金额和用途；
- 完工（已完成）后填实付总额，按登记顺序逐笔核销：垫付不足的部分记为尾款待补，多出的部分从最后一笔往前退；
- 未完工的事项不能结清；已结清的事项锁定状态与垫付记录，可撤销结算后重算；
- 事项被移除后，整笔记录（垫付 + 结算单）转入历史账，重开页面仍可查看，也可恢复到事项列表。

数据保存在 localStorage，不接后端、无新依赖。代码按业务拆为三个文件：记录 `src/records.js`、结算 `src/settlement.js`、页面 `src/main.js`。
