# 家庭维修费用垫付台

端口规划：`5114`

```bash
npm install
npm run dev
```

家里维修的钱分散在几名家人手里、师傅上门又有零散补付时，用这个页面把每笔垫付和最终结算对齐。数据只保存在浏览器 localStorage 中，无后端、无第三方依赖。

## 业务划分

- `src/records.js` —— 记录：维修事项与垫付笔次（付款人、金额、用途）的登记、状态维护、移除转历史账与恢复，负责 localStorage 持久化。
- `src/settlement.js` —— 结算：纯计算。完工后填写实付总额，按垫付的登记顺序逐笔核销；垫付不足的差额记尾款；垫付多出时从最后一笔往前退。未完工事项不允许结清。
- `src/page.js` —— 页面：渲染与事件委托，不直接算账、不直接读写 localStorage。
- `src/main.js` —— 入口，只负责启动页面。

## 规则

1. 每项维修可登记多笔垫付，按登记顺序编号。
2. 事项状态为「已完成」后才能填写实付总额并结清；未完工的不能结清。
3. 结算后垫付笔次锁定，可撤销结算重新填写。
4. 移除事项会连同垫付与结算记录一起转入「历史账」，重开页面仍可查看，也可恢复回事项列表。
